
# Simple Order

Dart warm-up laboratory exercise.

## Description

A simple ordering system using Dart that calculates item subtotals, order totals, and applies a 10% discount for orders worth ₱300 or more.

## Menu

| Item | Price |
|---|---:|
| Adobo rice | ₱85.00 |
| Iced tea | ₱35.00 |
| Turon | ₱25.00 |

## Sample Output

```text
Order for Guest
3 x Adobo rice     255.00
1 x Iced tea        35.00
3 x Turon           75.00
Subtotal           365.00
Discount 10%       -36.50
Total              328.50

Order for Juan
1 x Adobo rice      85.00
1 x Iced tea        35.00
2 x Turon           50.00
Subtotal           170.00
Total              170.00
```
